# 강의 자동 진행 스크립트 사용 매뉴얼

Oct 1, 2026 · @캡틴버기

## 준비 (최초 1회)

Python과 크롬이 설치된 상태에서, `auto_lecture.py`를 폴더(예: `C:\lecture`)에 저장하고 명령 프롬프트에 입력합니다.

```
pip install playwright
```

## 실습

**1단계. 실행** — 명령 프롬프트에 아래 두 줄을 입력합니다.

```
cd C:\lecture
python auto_lecture.py
```

**2단계. 로그인** — 새 크롬 창에서 로그인합니다. 처음 한 번만 하면 되고, 다음부터는 건너뜁니다.

**3단계. 강의 열기** — 같은 창에서 강의 플레이어를 엽니다. 터미널에 `강의 플레이어 감지`가 나오면 성공입니다. 이후 재생, 확인창, 다음 강의 이동은 모두 자동입니다.

## 종료와 꼭 기억할 것

마지막 강의가 끝나면 자동으로 종료됩니다. 중간에 멈추려면 크롬 창을 닫거나 터미널에서 `Ctrl + C`를 누릅니다.

- 강의는 스크립트가 띄운 크롬 창에서 열어야 합니다.
- 진행 중에는 터미널 창을 닫지 마세요.
- 크롬 창을 최소화하거나 PC가 절전 모드에 들어가면 재생이 멈출 수 있습니다.

## 안 될 때

| 증상 | 해결 |
| --- | --- |
| `No module named 'playwright'` | `pip install playwright` 다시 실행 |
| 강의를 열었는데 `감지`가 안 나옴 | 스크립트가 띄운 창에서 강의를 열었는지 확인 |
| 크롬 창이 열리지 않음 | 이전에 띄운 자동화 크롬 창을 모두 닫고 다시 실행 |
